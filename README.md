# Classic Arkanoid — 1986 Arcade Tribute

Профессиональная реализация легендарной аркадной игры **Arkanoid (1986)**, разработанная в рамках тестового задания. Проект написан на чистом JavaScript (ES6+ модули) с использованием графического движка **PixiJS v7** и библиотеки анимаций **GSAP**, строго соблюдая принципы ООП, изоляции компонентов и аутентичного ретро-визуала.

---

## Ключевые особенности и соответствие ТЗ

### Архитектура и Чистый Код
- **Нативные ES6-модули**: Проект разбит на логические модули без использования тяжелых сборщиков (Webpack/Vite), что позволяет запускать его локально через любой статический сервер.
- **Строгая инкапсуляция (ООП)**: Весь функционал изолирован по классам и функциям, исключая глобальные утечки данных (`window`).
- **Разделение ответственности**:
  - `Game.js` — главный класс-оркестратор (жизненный цикл, стейт-машина состояний, тикер, UI).
  - Сущности (`Paddle`, `Ball`, `Brick`, `PowerUp`) инкапсулируют собственное состояние и процедурную отрисовку.
  - Системы (`CollisionManager`, `LevelBuilder`) изолируют математику коллизий и генерацию уровней.

### Аутентичный Визуальный Стиль 1986 года
- **Процедурный пиксель-арт**: Игровые объекты (блоки, мяч, платформа «Vaus») отрисованы программно через `PIXI.Graphics` без тяжелых внешних текстур.
- **Объемный рельеф блоков**: Реализован эффект фасок (*beveled edges*) со световыми бликами сверху/слева и темными тенями снизу/справа.
- **Многоударные блоки**: Верхний ряд представлен серебряными блоками с прочностью **2 HP**, которые при первом попадании покрываются пиксельными трещинами и генерируют искры рикошета.
- **Ретро-типографика**: Подключен культовый шрифт **Press Start 2P** с кастомными отступами и фиксацией высоты строки во избежание подпрыгивания цифр счета.
- **Двухуровневый фон**: Раздельные пиксельные текстуры для окружения страницы (`page-bg.png`) и игрового поля (`canvas-bg.png`) с выключением сглаживания (`image-rendering: pixelated`).

### Игровые Механики и Бонусы (Power-ups)
- **Динамический угол отскока**: Угол полета мяча зависит от точки удара о платформу (эффект «физического подкручивания»).
- **Система выпадения капсул**: При уничтожении блоков с вероятностью 28% выпадает случайная капсула с буквой:
  - **`E` (Expand)** — расширяет платформу на 35% на 12 секунд.
  - **`D` (Disruption / Multiball)** — разделяет каждый активный мяч на 3 независимых мяча с разведенными векторами скорости.
  - **`S` (Slow)** — замедляет скорость всех мячей на 30% на 10 секунд.
- **Состояния игры**: Поддерживаются экраны *"Waiting / Click to Start"*, *"Playing"*, *"Game Over"* и *"Victory"* с полноценным рестартом.

## Инструкция по локальному запуску

Поскольку проект использует нативные **ES6-модули (`type="module"`)**, современные браузеры блокируют их загрузку по протоколу `file://` из-за политики безопасности CORS. Для корректной работы необходим локальный HTTP-сервер.

### Способ 1: Через VS Code (Рекомендуется)
1. Откройте папку проекта в редакторе **Visual Studio Code**.
2. Установите расширение **Live Server** (автор: Ritwick Dey).
3. Нажмите правой кнопкой мыши по файлу `index.html` и выберите **"Open with Live Server"**.

### Способ 2: Через Node.js (npx serve)
Если у вас установлен Node.js, выполните в терминале из корневой папки проекта:
```bash
npx serve .
```
Затем откройте в браузере появившийся адрес (обычно `http://localhost:3000`).

## Стек технологий
- **Core**: HTML5 Canvas, Vanilla CSS3 (Flexbox, Pixelated Rendering)
- **Language**: JavaScript (ES6+ Classes, Modules, Async/Await)
- **Engine**: PixiJS v7 (WebGL / Canvas 2D Rendering)
- **Animations**: GSAP (GreenSock Animation Platform)
- **Typography**: Google Fonts (Press Start 2P)
